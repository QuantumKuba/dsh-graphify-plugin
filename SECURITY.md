# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `@deepseek-ai/dsh-graphify`, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by emailing security@deepseek.com.
3. Include detailed information about the vulnerability, including reproduction steps, affected versions, and potential impact.

We take security seriously and will acknowledge receipt of your report, assess the impact, and release a patch as quickly as possible.
